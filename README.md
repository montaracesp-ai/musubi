# Boda Raúl & Judy

Web estática de nuestra boda, desplegada con GitHub Pages.

- `index.html` — contenido
- `styles.css` — estilos
- `script.js` — cuenta atrás (la fecha sale del atributo `datetime` de `#wedding-date`)

Para verla en local basta con abrir `index.html` en el navegador.

## Fotos

Las fotos van en `img/`. Cada hueco de la web es un `<figure class="ph" data-photo="img/...">`
con el nombre de archivo que espera: `fuji-pedida.jpg`, `japon.jpg`, `atardecer.jpg`, `paris.jpg`,
`nueva-york.jpg`, `edimburgo.jpg`, `logrono.jpg` y `sol.jpg`.
